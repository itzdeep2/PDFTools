# PDF Tools

I made this website to do some basic PDF work without installing any extra apps.

### Features
- Merge PDF files
- Extract a page from a PDF
- Convert PDF pages to JPG
- Add text to a PDF
- Read text from images
- Remove a PDF password if you know it
- Try to reduce PDF file size

### Built with
HTML, CSS and JavaScript. I used pdf-lib, PDF.js and Tesseract.js for the PDF tools.

The files are processed in the browser, so there is no backend.
